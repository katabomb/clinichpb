# clinichpb
診療所のホームページを簡単作成

1．基本コンセプト

診療所の簡単な情報を入力するだけで，本格的な診療所ホームページを瞬時に自動生成するWebアプリ．

遊びが主目的だが，実際の診療所でもある程度利用できる完成度．

基本方針は，「入力情報は最小限，出来上がるホームページは豪華に」．

2．設置・運用方式

項目	仕様
設置先	GitHub Pagesなどの静的Webサーバー
アプリ本体	HTMLファイル1個
使用技術	HTML，CSS，JavaScript
AI	使用しない
データベース	不要
サーバー側プログラム	不要
利用料金	基本無料
生成時間	ほぼ瞬時
生成サイトの共有	URLをコピーして送るだけ
