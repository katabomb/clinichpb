# CliniCraft（クリニクラフト）

**診療所の情報を入力して，ホームページを手軽に作るWebアプリ．**

CliniCraftは，診療所名や診療科，診療日などを入力し，デザインや文章を選ぶだけで，診療所のホームページ風サイトを作成できる小さなWebアプリです．まずは気軽に作って楽しむことを目的としています．

**[▶ CliniCraftを使ってみる](https://katabomb.github.io/clinichpb/)**

## できること

- 診療所名，院長名，住所，電話番号，FAX番号，診療科，診療日などを入力
- 複数のデザインから好みの雰囲気を選択
- キャッチコピー24種類，紹介文24種類，院長あいさつ8種類から文章を選択（合計56種類の候補）
- トップページ，診療案内，医院紹介，アクセスなどを切り替えて表示
- 作成したサイトを共有URLやQRコードで紹介
- 共有URLを開いて内容を再表示し，編集することも可能

入力していない項目は，可能な範囲で表示を省略します．架空の設備や資格，診療内容を自動で付け足すことは意図していません．

## 使い方

1. 上の「CliniCraftを使ってみる」からアプリを開きます．
2. 診療所の基本情報を入力し，診療科や診療日を選択します．
3. 「ホームページを表示」を押すと，サイトが表示されます．
4. 表示後の操作パネルから，デザインや文章を変更できます．
5. 「共有URL・QRコードを表示」から，完成したサイトのURLをコピーしたり，QRコードを保存したりできます．

特別なアカウント登録やソフトウェアのインストールは不要です．

## 仕組み

このアプリは，**HTML・CSS・JavaScriptをまとめた単一の `index.html`** で動作します．サーバー側でページを生成する仕組みや，データベースは使用していません．

| 項目 | 内容 |
| --- | --- |
| 動作環境 | 一般的なWebブラウザ |
| 使用技術 | HTML / CSS / JavaScript |
| アプリ本体 | `index.html` 1ファイル |
| 公開方法 | GitHub Pagesなどの静的ホスティング |
| サーバー側プログラム | 不要 |
| データベース | 不要 |
| 実行時のAI API | 不使用 |
| 共有方法 | 設定情報を含むURLとQRコード |

### 文章とデザイン

文章の候補はアプリ内にあらかじめ用意されています．実行時にAIが文章を生成するのではなく，候補を選んで組み合わせる方式です．文章の原案作成にはAIを活用しています．

### URLによる共有

作成したサイトの情報は共有URLの一部（`#` 以降）に含まれます．共有先のブラウザがその情報を読み取り，同じアプリ上でサイトを再現します．

したがって，**診療所ごとに別々のHTMLファイルをサーバーへ保存する仕組みではありません**．また，URLの情報は秘密情報として保護されるものではありません．

## 自分で動かす・改造する

このリポジトリの `index.html` を取得し，Webブラウザで開くと基本的な画面を確認できます．共有URLなどの動作を含めて試す場合は，GitHub Pagesなどの静的Webサーバーで公開してください．

ソースコードは [index.html](./index.html) から確認できます．特別なビルドツールやパッケージのインストールは必要ありません．

## 利用上の注意

- **実在する診療所の公式サイトとして使う場合は，公開前に内容を必ず確認してください．** 診療時間，休診日，所在地，連絡先，標榜診療科などの正確性は利用者側で確認する必要があります．
- 患者情報などの個人情報，公開したくない情報は入力しないでください．共有URLに入力内容が含まれます．
- 共有URLが長くなる場合があります．URLやQRコードが利用環境によって扱いにくくなることがあります．
- GitHub Pagesで公開する場合，サービス側の利用条件や制限が適用されます．
- 検索エンジンへの登録や独自ドメインでの本格運用を前提に設計したものではありません．

## 開発の背景

診療所のホームページを作るとき，必要な情報を入力するだけで，それらしいサイトができたら面白いのではないか．そんな発想から作った個人制作のアプリです．

目指したのは大規模なホームページ制作サービスではなく，**少ない入力で，ちょっと立派な診療所サイトを作って楽しめること**．静的なHTMLファイル1個でどこまでできるか，という試みでもあります．
